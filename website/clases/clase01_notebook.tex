\subsection{Librerías en R}\label{libreruxedas-en-r}

Dentro de R existen librerías, las que pueden ser definidas como
colección de módulos; estos, no son más que bloques de códigos generados
para un fin particular.

\subsection{Ejemplos de librerías}\label{ejemplos-de-libreruxedas}

Algunas de las librerías más conocidas son:

\subsubsection{\texorpdfstring{\textbf{Dplyr}}{Dplyr}}\label{dplyr}

Librería orientada a la manipulación de datos.

Cheat Sheet:
https://nyu-cdsc.github.io/learningr/assets/data-transformation.pdf

\subsubsection{\texorpdfstring{\textbf{Ggplot2}}{Ggplot2}}\label{ggplot2}

Corresponde a la principal librería para graficar.

Cheat Sheet:
https://www.maths.usyd.edu.au/u/UG/SM/STAT3022/r/current/Misc/data-visualization-2.1.pdf

\subsubsection{\texorpdfstring{\textbf{Tidyverse}}{Tidyverse}}\label{tidyverse}

Biblioteca de librerías orientada a la manipulación de datos.

Dichas librerías son tres de una gran variedad de librerías que pueden
ser utilizadas en R. Lo relevante es que para ser utilizadas se debe
generar un proceso de instalación y llamado previo de dichas librerías.

Otra librerías se pueden encontrar en el siguiente enlace:
https://posit.co/resources/cheatsheets/

\subsection{Instalación y llamado}\label{instalaciuxf3n-y-llamado}

Para la utilización de dichas librerías debemos seguir dos pasos:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Instalación.
\item
  Llamado
\end{enumerate}

Para la instalación de librerías en R en modalidad local (en el
computador) se debe utilizar el siguiente código:

\begin{verbatim}
install.packages("nombre del paquete")
\end{verbatim}

Asumiendo que ya tenemos instalada la librería, cada vez que utilicemos
un código de la librería debemos realizar el llamado. Esto se realiza de
la siguiente manera:

\begin{verbatim}
install.packages("dplyr")
library(dplyr)

datos = iris

select(datos, Species)
\end{verbatim}

En este caso, estamos haciendo un llamado a la librería \textbf{dplyr}
para utilizar una de sus funciones que corresponde a \textbf{select}, la
que permite seleccionar una columna de un set de datos llamado
\textbf{iris}.

En el caso de utilizar una función de una librería no cargada, generará
un error del siguiente tipo: \textbf{could not find function}. Por
ejemplo:

\begin{verbatim}
vtree(FakeData,"Severity Sex",sameline=T)
\end{verbatim}

\begin{Shaded}
\begin{Highlighting}[]
\FunctionTok{install.packages}\NormalTok{(}\StringTok{"dplyr"}\NormalTok{)}
\end{Highlighting}
\end{Shaded}

Realizamos el llamado

\begin{Shaded}
\begin{Highlighting}[]

\end{Highlighting}
\end{Shaded}

Utilizamos la librería

\begin{Shaded}

\NormalTok{datos }\OtherTok{=}\NormalTok{ iris}
\FunctionTok{select}\NormalTok{(datos, Species)}
\end{Highlighting}
\end{Shaded}

Por ejemplo, si no tenemos cargada una librería:

\begin{Shaded}

\FunctionTok{detach}\NormalTok{(}\StringTok{"package:dplyr"}\NormalTok{, }\AttributeTok{unload =} \ConstantTok{TRUE}\NormalTok{)}

\subsection{Pipe operator}\label{pipe-operator}

\subsection{Data Frames}\label{data-frames}

Un dataframe es un caso especial de lista, utilizada para guardar las
tablas de datos. Posee la estructura clásica fila columna.

Nota: Mientras en un comienzo se usan \texttt{data.frame}, más adelante
al trabajar con \texttt{tidyverse} se utilizan \texttt{tibble} que
corresponde a un concepto evolucionado de dataframe; de manera más
específica corrige algunos comportamientos propios del dataframe, al no
interpretarse los strings como factor por defecto y no existir
\texttt{rownames}.

\subsection{Tidyverse}\label{tidyverse-1}

Como parte de los desarrollo de \href{http://hadley.nz/}{Hadley
Wickham}, la librería
\href{https://www.tidyverse.org/}{\texttt{tidyverse}}, corresponde a un
ecosistema orientado a las ciencias de datos, con paquetes que comparten
la orientación de trabajo en relación a los datos.

Por ejemplo, permiten la utilización del pipe operator.

\subsubsection{Tibbles}\label{tibbles}

Corresponde a la versión de dataframe en \texttt{tidyverse}. Se trabaja
igual, pero con ciertas mejoras. Se pueden crear de tres maneras:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Crear usando \texttt{tibble()}
\item
  Usando explicitamente \texttt{as\_tibble()} en una tabla.
\item
  Cuando se aplica una función de \texttt{dplyr} en un dataframe, se
  convierte a tibble.
\end{enumerate}
